📊 Flipkart Laptop Sales Analysis | Power BI Project

Project Overview-

This Power BI project analyzes Flipkart laptop sales data to uncover insights into pricing trends, brand performance, customer ratings, discount strategies, and category distribution.

The dashboard is designed to support data-driven business decision-making by transforming raw e-commerce data into interactive and actionable visual insights.

The project demonstrates end-to-end BI capabilities including data modeling, DAX calculations, Power Query transformation, and Power BI Service readiness.

Tools & Technologies:

Power BI (Dashboard Development),
Power Query (Data Cleaning & Transformation),
DAX (Advanced Calculations & KPIs),
Excel (Raw Data Preparation),
Data Modeling (Star Schema Concepts),
Power BI Service (Deployment Concepts),
Dataflows (Explored for reusable ETL pipelines)

📈 Key Performance Indicators(KPIs):
💰 Total Sales: 55M
📦 Total Products: 718
⭐ Average Rating: 3.58
💸 Average Discount Rate: 73.46%

📊 Dashboard Features:
Interactive slicers (Product ID, Brand, OS, Category),
KPI cards for key business metrics,
Brand-wise sales performance analysis,
Category segmentation (Excellent, Good, Average, Needs Improvement),
OS-based sales distribution (Windows vs Others),
Ratings distribution across brands,
Toggle view (Chart View / Table View),
Fully interactive filtering for business exploration

🧠 Key Business Insights:
💻 Windows dominates laptop sales across all segments
💸 High discount rates (~73%) strongly influence purchase behavior
🏆 A small group of top brands contributes the majority of total revenue
📊 “Excellent” category laptops generate the highest revenue share
⭐ Ratings vary significantly across brands, indicating product quality differences

🧮 DAX Measures & Analytics:
-Total Sales Calculation (Revenue aggregation)
-Average Rating measure
-Discount Percentage KPI
-Product count metrics
-Brand-level and category-level aggregations
-Dynamic filtering using slicers and measures

🔄 Data Transformation & Modeling:
Cleaned and transformed raw dataset using Power Query,
Handled missing values and standardized product categories,
Built relationships between product, category, and sales tables,
Designed optimized data model for performance and scalability,
Applied star schema principles for analytical efficiency

Power BI Service & Advanced Concepts:
Structured dataset for refresh-ready Power BI Service deployment,
Explored Dataflows in Power BI Service for centralized and reusable data preparation,
Applied performance optimization techniques for smoother dashboard interaction,
Designed model with scalability for enterprise-level reporting

Project Objectives:

This project demonstrates the ability to:
Build end-to-end Power BI dashboards from raw data,
Apply DAX for business KPIs and analytics,
Clean and transform data using Power Query,
Design efficient data models for reporting,
Extract actionable business insights from e-commerce data,
Apply Power BI Service concepts for scalable BI solutions
